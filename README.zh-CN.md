# Agenda · v0.4.0

**本地优先的多 AI 协作桌面工作台。** Agenda 把 **Claude Code**、**Codex**、**Gemini**、**DeepSeek**、内嵌 **Pi** 以及自定义 **ACP** 智能体放进同一个空间，让它们围绕同一个项目文件夹讨论方案、拆解分工并协同修改文件。你可以从圆桌讨论开始，也可以把其他 AI 工具里聊到一半的会话直接导进来继续做——在确认计划、审批命令、审查代码改动或合并进 Git 时随时介入。

## 为什么做 Agenda？

大多数 AI 编程与写作工具都把你限制在单一模型或单条对话线程里。当你想听取不同模型的第二意见，或者让一个 AI 负责架构设计、其他 AI 分别负责编码实现和代码审查时，往往只能在不同窗口之间反复复制粘贴提示词和文件路径。

Agenda 为多个 AI 提供了一个共享的协作现场：

- **同一文件夹，多 AI 同场协作** —— 本机 CLI 工具（直接复用你已有的登录账号与订阅额度）、API 模型、内嵌 `pi` 编程代理和自定义 ACP 工具可以在同一个空间里混搭使用。
- **两种协作模式无缝衔接** —— 在**聊天空间**里头脑风暴、共同改稿，方案定下后一键转入**任务空间**，按依赖关系图并行推进。
- **结构化记忆，告别上下文膨胀** —— 自动将讨论共识沉淀为带消息编号引用（`#N`）的**空间记忆库**，配合滚动更新的**前情提要**与长会话**自动交接**，既省 token 又不丢上下文。
- **跨软件接力** —— 直接读取本机 Claude Code、Codex、Gemini CLI、DeepSeek Harness、WorkBuddy、ZCode 的历史会话，或导入 ChatGPT、Claude.ai 等网页版导出文件，无需从头交代背景。
- **始终由你掌控** —— 四档工作区权限、命令运行审批卡片、diff 逐行批注，以及基于 Git worktree 的并行隔离执行，确保每一步改动清晰可控。

## 两种协作空间

| 空间类型 | 适用场景 | 协作方式 |
| --- | --- | --- |
| **聊天空间** | 方案讨论、架构评审、协同写作、交互式改文件 | 多名成员围绕共享文件夹依次发言、互相回应。支持用 `@成员` 点名、用「只问 TA」指定单人回答，并可随时插话、跳过或停止。当空间只选 1 名成员时，自动切换为**单人聊天**——不设轮次上限，并在引擎支持时启用私有长会话。 |
| **任务空间** | 多步骤开发实现、重构、多模块并行交付 | 向**协调者**给出目标。若目标存在歧义，协调者会先提出最多 3 个带默认答案的澄清问题，再拆解出带依赖关系的子任务图与前提假设。**工作者**按依赖执行：Git 项目在独立的 `git worktree` 中并行处理，普通文件夹按顺序修改；子任务完成后停在待审查状态，由你确认并合并。 |

### 从讨论到交付的完整闭环

1. **讨论转任务** —— 在聊天空间敲定方案后，勾选关键消息点击「转到任务空间」，可以直接原样带入，也可以指定成员提炼成结构化方案后再创建。
2. **执行中随时调度** —— 子任务运行期间，你发送的新想法会统一交给协调者判断：不冲突的要求作为补充说明分发给对应子任务；存在冲突时自动暂停受影响的子任务并修订计划；普通提问则直接回答。
3. **审查、合并与回传** —— 任务完成后，协调者会生成汇总报告。对于 Git 项目，点击合并时协调者会参照仓库近期提交风格自动起草 commit 说明；结束任务时还可将总结一键发回原聊天空间。

## 核心特性

### 1. 灵活混搭各类 AI 引擎

同一个空间内可以添加不同引擎，也可以将同一种 AI 添加为多名成员，分别配置角色设定、模型来源、具体型号与思考档位：

| 接入方式 | 支持的引擎与模型 | 配置说明 |
| --- | --- | --- |
| **本机命令行程序** | **Claude Code**、**Codex**、**DeepSeek Harness** (`dsh`)、**Gemini CLI** | 直接使用你在对应工具中的登录状态与套餐额度。支持自动检测或手动指定路径；Claude Code 还可绑定第三方 Anthropic 兼容接口作为模型来源。 |
| **内嵌 `pi` 代理** | 配合任意 OpenAI 兼容接口获得完整读写与命令执行能力 | 随 Agenda 内置打包，无需额外安装。在下方配置好 API 接口后即可选择 `Pi · <接口>`，支持直接读写文件、运行命令及挂载 Skill / MCP。 |
| **自定义 AI（ACP）** | 支持 **Agent Client Protocol**（stdio JSON-RPC）的命令行 AI | 在「设置 → AI 连接 → 自定义 AI（ACP）」填写名称、启动命令与参数，保存时自动测试握手，并将文件修改与命令请求接入审批卡片。 |
| **Gemini API** | Google Gemini 系列模型 | 填写 Gemini API 密钥（可选自定义接口地址）。 |
| **OpenAI 兼容接口** | DeepSeek、通义千问、Kimi、智谱、OpenAI、本地 **Ollama** 等 | 填写接口地址、模型名称与密钥（Ollama 等本地服务密钥可留空），可按需勾选「也给 Claude Code 用」。 |

### 2. 空间记忆库与上下文预算管理

针对多 AI 长讨论容易撑爆上下文窗口或遗忘早期决定的痛点，Agenda 内置了完整的上下文治理机制：

- **结构化空间记忆库** —— 自动将讨论共识整理为**决定**、**约束**、**偏好**、**项目事实**、**否决过**（区分「用户否决」与带引擎/模型快照的「试过走不通」）、**问题 / 提议 / 分歧**和**任务结果**，记录原因、强制核验出处（`#N`），并在消息写完时零 token 同步归档原文（`messages/<seq>.md`）。
- **分层注入、缓存护航与节流整理** —— 按成员职责与子任务依赖分层注入，优化 Prompt 顺序保住公共前缀（`imports → L1 → history → L2/extras`），裁剪时保底必守硬约束；后台整理采用无工具隔离与空闲防抖节流，并支持在设置里指定全局便宜 API 整理模型，既省 token 又不跨空间串味。
- **前情提要与自动交接** —— 较早的聊天记录滑出窗口时自动生成可编辑、带防覆盖保护的**前情提要**；当长会话上下文占用达到设定阈值（默认 50%）时，在空闲间隙自动撰写交接说明并平滑切换至新会话。
- **可纠偏的记忆库与上下文面板** —— 成员标签实时展示上下文占用圆环与额度提醒；右侧栏「上下文」面板查看最近一次构造的上下文估算或手动重开会话；「记忆库」面板支持一键**采纳 / 驳回**分歧与提议、**回答**问题、**修改**、**作废**（严格只追加、受强鉴证保护）及**立即整理**，存在待确认分歧时在右栏亮起提示红点。

### 3. 角色卡、团队、Skill 与 MCP 资源库

点击左侧栏「资源库」，统一管理跨空间复用的能力组件：

- **角色卡与预设团队** —— 内置 7 张中英双语角色卡与常用协作团队，支持自定义修改、一键恢复默认，以及单文件 Markdown 导出与带预览导入。
- **Skill 与 MCP 管理** —— 自动扫描本机已安装的 Skill 与 MCP 服务，或从内置「集市」检索安装；支持跨 AI 链接 Skill，并将 MCP 密钥独立存储在 Agenda 中，不污染其他 CLI 工具的全局配置。
- **成员级隔离挂载** —— 为内嵌 `pi`、Claude Code 和 Codex 成员按需勾选挂载的 Skill 与 MCP；若在低权限空间挂载了包含写操作的 MCP，会自动弹窗提示提权、暂不挂载或取消。

### 4. 导入外部对话与按主题交接

无需重新交代背景，把其他 AI 软件里的对话直接带进新空间或现有空间：

- **自动读取本机会话** —— 只读扫描本机 **Claude Code**、**Codex**、**DeepSeek Harness**、**Gemini CLI**、**WorkBuddy / CodeBuddy** 和 **ZCode** 的会话记录，绝不改动原软件文件。
- **粘贴文本或上传导出文件** —— 支持直接粘贴聊天记录，或拖入 **ChatGPT**、**Claude.ai**、**Gemini 网页版**等导出的 `.zip`、`.json`、`.md`、`.txt` 文件。
- **Claude Code 原生接续与补导** —— 导入 Claude Code 会话时，可从导入的最后一条消息处复制分支接着聊，保留原先读过的文件上下文；若原会话后续又有新对话，可在空间内一键「补导」新增内容。
- **4 种上下文整理方式** —— 支持**保留全部原文**、**较早部分压成摘要**、**生成 Markdown 交接文档**，或选择**按主题**导入（提取指定关键词相关的背景、决定、约束和待办，生成共享文件夹里的 `主题-<名称>.md` 简报供团队接手）。

详细步骤与各软件记录位置见 [对话导入指南](docs/usage.md#导入别处的对话) 与 [导入来源列表](docs/importers.md)。

### 5. 文件审阅、逐行批注与定时任务

- **文件树与 Diff 逐行批注** —— 在右侧栏直接预览、编辑和新建共享文件；查看每轮改动的 diff 对比并支持单步撤销（文件后续被改过时会先提醒）。在 diff 上点击或按住 Shift 连选行号即可添加多条**逐行批注**，一键汇总发送为 `@成员` 的修改意见。
- **图片与文件附件** —— 支持拖拽或粘贴（`Ctrl+V` / `⌘V`）图片与文件到输入框。支持看图的引擎会直接收到新增图片；普通文件会复制到共享文件夹的 `附件/`（英文界面为 `attachments/`，Git 项目中自动写入 `.git/info/exclude` 避免污染提交）。
- **定时任务** —— 在空间设置或全局设置中配置单次、每周或固定间隔调度，自动创建任务空间或向聊天空间发送指令。启用定时任务时，关闭主窗口会自动收纳到系统托盘或菜单栏后台待命。

### 下载安装包

前往 [**GitHub Releases**](https://github.com/xxxpixel-x/ai-agenda/releases/latest) 下载对应系统和架构的安装包：

| 系统与架构 | 安装包文件名 |
| --- | --- |
| **Windows 10 / 11（x64）** | `Agenda-<版本>-win-x64.exe` |
| **macOS（Apple 芯片）** | `Agenda-<版本>-mac-arm64.dmg` |
| **macOS（Intel 芯片）** | `Agenda-<版本>-mac-x64.dmg` |
| **Linux（x64）** | `Agenda-<版本>-linux-x86_64.AppImage` 或 `Agenda-<版本>-linux-amd64.deb` |

<details>
<summary><strong>未签名安装包首次打开说明（Windows / macOS / Linux）</strong></summary>

安装包目前尚未进行代码签名，首次启动请按系统提示处理：

- **Windows**：遇到 SmartScreen 提示时，点击「更多信息」→「仍要运行」。
- **macOS**：打开 DMG 后将 **Agenda** 拖入「应用程序」，在「应用程序」中右键点击 **Agenda** 选择「打开」。若提示“应用已损坏”，请在终端执行 `xattr -cr /Applications/Agenda.app` 后再次打开。
- **Linux（AppImage）**：首次运行前先赋予可执行权限：`chmod +x Agenda-*.AppImage`。

</details>

### 从源码运行

需要 **Node.js 22.19.0 或以上**（使用 Git 项目并行执行任务时还需安装 **Git**）。

```sh
git clone https://github.com/xxxpixel-x/ai-agenda.git
cd ai-agenda
npm ci
npm start
```

- **免账号体验演示模式**（使用模拟 AI 与独立的 `data-mock/` 目录）：
  ```sh
  npm run mock
  ```
- **Windows 快捷启动**：可直接双击项目根目录下的 `启动.cmd`（首次运行会自动安装依赖）；执行 `npm run build:launcher -- -DesktopShortcut` 可在项目内生成 `Agenda.exe` 启动器并创建桌面快捷方式。

## 快速上手

1. **连接 AI** —— 打开左下角「设置 → AI 连接」。已安装并登录的本机命令行工具会自动识别；按需配置 API 密钥或添加自定义 ACP 工具。
2. **创建空间** —— 选择新建**聊天空间**或**任务空间**（或直接「从对话开始」），挑选成员或从「角色卡 / 团队」一键载入阵容，选择已有项目文件夹或使用 Agenda 创建的托管文件夹。
3. **开始协作** —— 在聊天空间直接发消息或 `@` 点名；在任务空间回答协调者的澄清问题（如有），在右侧「计划」面板查看或调整子任务依赖图后开始执行。
4. **审阅与合并** —— 在可收起的右侧栏切换「文件」「改动」「计划」（任务空间）「上下文」和「记忆库」，逐行批注 diff、审查子任务产物，并在 Git 任务完成后一键合并到当前分支。

在「设置 → 通用」中可随时切换**中文 / English / 跟随系统**、切换深浅色主题、开关后台系统通知、开启 AI 工作时防睡眠、调整自动交接的上下文阈值，以及按需指定全局记忆整理模型（推荐便宜 API 接口）。

## 权限、安全与本地数据

- **四档空间权限**：
  - **只读** —— 仅浏览文件与讨论，不可修改工作区文件。
  - **可改文件** —— 可读写共享文件夹内的文件。
  - **可运行命令** —— 共享文件夹是命令的起始目录。聊天空间中，支持审批的引擎可在运行命令前弹出审批卡片。不支持审批的聊天引擎按「可改文件」运行。
  - **全部权限** —— 不受共享文件夹范围与命令审批限制。
  - **内嵌 Pi** —— 终端使用当前系统账号，可访问共享文件夹以外的位置。「可运行命令」档的每条命令和每次可写 MCP 调用都需要单次批准；缺少交互审批通道时（例如无人值守的任务子任务）会禁用命令和可写 MCP。只读目录（如空间记忆库）仍受文件工具只读保护。
- **凭据与密钥保护**：
  - API 密钥与 MCP 密钥保存在本机数据目录中，系统加密（`Electron safeStorage`）可用时自动加密存储，不可用时回退为明文（请勿对外分享配置文件）。
  - 向直接接入的 API 模型发送工作区文件快照时，会自动排除 `.env`、`.npmrc`、`.pypirc`、SSH 私钥及 `.pem`/`.key` 证书等常见敏感文件。
- **本地数据存储位置**：
  - **安装版**：Windows 为 `%APPDATA%\Agenda\data`，macOS 为 `~/Library/Application Support/Agenda/data`，Linux 为 `~/.config/Agenda/data`
  - **源码版**：正常模式使用项目下的 `./data/`，演示模式使用 `./data-mock/`
- **文件历史与卡死兜底**：
  - 内置文件历史最多跟踪 3,000 个不超过 1 MiB 的文本文件；大文件与二进制文件请依赖 Git 或项目备份。
  - 命令行 / Pi 连续 20 分钟无输出、API 流连续 10 分钟无数据时会自动终止并报错，避免任务无限期挂起（可通过环境变量 `RT_IDLE_MINUTES` 调整，等待命令审批期间不计时）。
