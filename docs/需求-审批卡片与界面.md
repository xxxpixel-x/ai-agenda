## 一、审批卡片

### 什么时候弹

| 空间权限 | 运行命令 | 改文件 |
| --- | --- | --- |
| 只读 / 可改文件 | 本来就不能运行 | 不变 |
| **可运行命令** | **先弹卡片问你** | 直接改，不问 |
| 全部权限 | 直接运行，不问 | 直接改，不问 |

- 只在**聊天发言**中弹出。任务协作里后台干活的 AI 不弹，照现在的方式执行。
- AI 之间请求越界时先问你的规则不变。

### 各 AI 的情况

| AI | 做法 |
| --- | --- |
| Claude Code | 用 `--permission-prompts host` 加 stream-json 双向通信，在它运行命令前由软件回答允许或拒绝 |
| Codex | 从 `codex exec` 改成 `codex app-server`（JSON-RPC）来接收审批请求。这个协议是实验性的，**实测不通就按下一行处理** |
| DeepSeek Harness | 后台模式没法问人：在「可运行命令」档**不让它运行命令**，只能读写文件；成员标签上提示「不能运行命令」 |
| API 成员（Gemini、OpenAI 兼容） | 本来就不能运行命令，不受影响 |

### 卡片

- 出现在这个 AI 的发言气泡里，位于动作列表下方，显示它想运行的完整命令（太长时折叠）。
- 三个按钮：**允许**、**一直允许 `npm`**、**拒绝**。
  - 「一直允许」按程序算：允许过 `npm test` 之后，所有 `npm` 开头的命令都不再问。用 `&&`、`|`、`;` 连起来的命令，每一段的程序都放行过才不问。
  - 点「拒绝」后可以补一句理由（也可以不填），理由会转告 AI，它接着往下做。
- 处理完的卡片收成一行，例如「已允许 npm test」「已拒绝 rm -rf build：先别删」。
- 没人处理就一直等。点「停止」可以随时中止，卡片会标记为已取消。
- 放行记录保存在空间里。空间设置里新增「已放行的程序」列表，每一项都可以删掉。

### 提醒

- 侧栏里这个空间显示「等你确认」标记，切到别的空间也看得到。
- 窗口不在前台时，任务栏图标会一直闪，直到你切回窗口。

## 二、界面小改

1. **点成员标签直接换型号**：点顶栏的成员标签，弹出这个成员的型号和思考档位，选完立即保存，下一次发言开始生效，不用再进空间设置。
2. **侧栏显示最后一条消息**：空间条目第二行的日期换成最后一条消息的预览（「发言人：内容」，只显示一行），时间放到右上角。状态标记三选一：正在发言、等你确认、任务需要你处理。
3. **任务需要你时，在聊天里也能看到**：任务协作在等你确认计划、审查或回答问题时，聊天输入框上方出现一条提示，例如「任务协作：等你审查『登录页』」，点「去处理」就切到任务页的对应位置。
