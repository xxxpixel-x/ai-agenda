## 需求

### 1. 计划自动确认（已并入 [任务空间](需求-任务空间.md)，2026-11-18 完成）

- 起因：2026-11-14 对比 Grok Bot 后提出，想让任务协作做到"发一个目标，自动做完"。
- 现在：协调者定好计划后，必须等你确认才开始执行。
- 想要：任务协作里在「做完自动通过」旁边加一个「计划定好直接开始」。勾上后，协调者定稿（包括其他成员审阅过的）就直接开始执行，计划照样显示在任务面板里，随时可以暂停或取消。
- 两个都勾上时，除了最后合并进项目，全程不用点。
- 待定：要不要再加一个"做完自动合并"，让 Git 项目也全程不用管？

- 起因：同上。比如每天早上跑一遍测试、整理当天的资料。
- 已定：错过的时间点直接跳过，记进运行记录；设了定时任务时关窗口缩到托盘。

### 3. 完成通知

- 起因：同上。
- 现在：只有等你确认命令时，任务栏图标会闪。
- 想要：窗口不在前台时，发系统通知：
  - 任务协作做完、失败；
  - 等你处理：确认计划、审查、回答问题、命令审批卡片。
  - 点通知切回窗口，直接跳到要处理的地方。
- 设置里可以关掉。

## 不做

- 云端运行、登录邮箱 / 网站 / 办公软件替你干活（Grok Bot 那类）：和"你在场的协作会议室"这个定位不符，安全风险也大。
- Orca / OpenMausBot 里的云端或虚拟机、操控电脑、外部应用连接、Gmail / webhook 触发、手机配对、内置浏览器、手机模拟器、分屏终端、插件市场、语音、GitHub / Linear 任务面板：同上，或者是把 Agenda 往 IDE 方向做。
- magpie 那类本机模型网关、多账号自动切换、按意图分派模型、隐私遮盖：太重，也不是 Agenda 的定位。用户自己装了 magpie，Agenda 照样能用。
