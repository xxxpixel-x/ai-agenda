# 待办：需求与 Bug

## 需求

### 1. 计划自动确认

- 起因：2026-11-14 对比 Grok Bot 后提出，想让任务协作做到"发一个目标，自动做完"。
- 现在：协调者定好计划后，必须等你确认才开始执行。
- 想要：任务协作里在「做完自动通过」旁边加一个「计划定好直接开始」。勾上后，协调者定稿（包括其他成员审阅过的）就直接开始执行，计划照样显示在任务面板里，随时可以暂停或取消。
- 两个都勾上时，除了最后合并进项目，全程不用点。
- 待定：要不要再加一个"做完自动合并"，让 Git 项目也全程不用管？

### 2. 定时任务

- 起因：同上。比如每天早上跑一遍测试、整理当天的资料。
- 想要：在空间里设定时间（每天几点 / 每周几 / 每隔多久），到点自动发起一次任务协作（写好目标）或者在聊天里发一条消息。权限按这个空间的设置。
- 限制：只在电脑开着、Agenda 开着时运行，不做云端。
- 待定：
  - 错过的时间点（当时没开机）是下次打开时补跑一次，还是直接跳过？
  - 现在关窗口就退出。要不要改成关窗口后留在托盘 / 菜单栏里继续运行？

### 3. 完成通知

- 起因：同上。
- 现在：只有等你确认命令时，任务栏图标会闪。
- 想要：窗口不在前台时，发系统通知：
  - 任务协作做完、失败；
  - 等你处理：确认计划、审查、回答问题、命令审批卡片。
  - 点通知切回窗口，直接跳到要处理的地方。
- 设置里可以关掉。

### 4. macOS / Linux 统一适配

- 起因：2026-11-15 决定，近期的改动先只在 Windows 上做和验证，不逐个同步到 macOS / Linux，最后统一再改。
- 待同步：
  - 中英双语与语言设置（左下角「设置」，跟随系统 / 中文 / English）：确认 macOS / Linux 上系统语言识别正确、Electron 弹窗与菜单文字切换正常。
  - 左下角「连接与登录」改名「设置」；顶部空间的「设置」改名「空间设置」。
- 统一改时：在 macOS / Linux 上实际跑一遍，必要时补平台相关代码，并更新安装包与 README 的平台说明。
