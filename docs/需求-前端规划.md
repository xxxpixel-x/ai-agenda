# 需求：前端重新规划

- 整理：2026-11-18
- 起因：接下来要加角色卡、集市、定时任务、自定义 AI、额度和上下文，现在的设置窗口和右侧栏放不下。整体重新规划，右侧栏参考 Claude 桌面版。
- 不换框架：继续用现在的纯 JS 加 CSS，不引入 React 或打包工具。要的是统一的视觉风格，不是现成组件。
- 视觉参考：2026-11-19 定为 Claude Code 和 Gemini 的界面，加上 Gemini 的粒子效果（见第七节）。
- 2026-11-19 定下：
  - **成员栏**留在空间顶部，样式改轻；上下文小圈放在成员标签上。
  - **聊天区**改成无气泡、全宽排版（像 Claude Code / Gemini）：小头像加名字区分成员，你发的消息稍微区分一下。
  - **粒子效果**只用两处：欢迎页；AI 正在思考、还没吐字时，它那条消息的占位处（开始输出就收起）。记忆库展示页以后再说。
  - **节奏**：先做样式变量和欢迎页、聊天空间、全局设置三个页面，截图给你确认方向，再铺开到其余页面。

## 一、全局设置：整页，左侧导航

左下角「设置」打开后占满主区域，左边分类、右边内容，像系统设置那样。

| 分类 | 放什么 |
| --- | --- |
| 通用 | 语言、提醒、防睡眠、关窗口时缩到托盘 |
| AI 连接 | 每个 AI 一行：图标、名字、状态、额度。点开才显示程序位置、API key 等。自定义 ACP 接入也在这里（见 [需求-ACP接入](需求-ACP接入.md)） |
| 定时任务 | 所有空间的定时任务和运行记录（见 [需求-定时任务](需求-定时任务.md)） |

- 现在的设置窗口里每个 AI 都整块摊开；改成默认每个只显示一行，一眼看清哪些能用，要改的时候才展开。
- 分类以后再多也放得下，加功能不用改布局。

## 二、资源库：侧栏单独一个入口

- 位置在侧栏左下角「设置」旁边。
- 打开后同样是整页、左侧导航：角色卡、团队、skill 与 MCP、集市（见 [需求-角色卡](需求-角色卡.md)）。

## 三、空间设置：顶部标签

| 标签 | 放什么 |
| --- | --- |
| 常规 | 名字、共享文件夹、权限、已放行的程序、每次最多来回几次（聊天空间） |
| 成员 | 成员列表，从角色卡或团队添加；任务空间还有协调者 |
| 任务选项 | 只在任务空间：计划确认方式、审阅、自动通过、最多同时做几个 |
| 定时 | 这个空间的定时任务 |

## 四、新建空间

- 还是一个窗口。成员那一栏改成「从角色卡或团队添加」，也能像现在这样直接选 AI。
- 默认只露出最常用的几项，其他的收起来。

## 五、右侧栏：多面板

参考 Claude 桌面版的右侧栏：能收起，顶部切换几个面板，一次看一个。当前空间用不上的面板不显示。

| 面板 | 放什么 | 现在 |
| --- | --- | --- |
| 文件 | 共享文件夹、Markdown 预览、右键菜单 | 已有，右键菜单见 [需求-小功能](需求-小功能.md) |
| 改动 | 每次改动、对比、逐行批注 | 已有，批注见 [需求-小功能](需求-小功能.md) |
| 计划 | 任务空间的子任务、依赖、状态 | 现在是聊天上方的一条，挪进来，聊天区更清爽；聊天空间不显示 |
| 上下文 | 每个成员看到了什么 | 新加，见 [需求-上下文与额度](需求-上下文与额度.md) |

## 五点五、侧栏

- 单人聊天（只有一个成员的聊天空间）显示这个 AI 的头像，多人聊天空间和任务空间照旧用各自的图标（见 [需求-单人聊天](需求-单人聊天.md)）。

## 六、成员标签

- 加一个小圈，表示上下文用了多少，快满时变色。
- 鼠标停上去一次显示「上下文 X%、额度 Y%」。拿不到的数字就不显示。

## 七、视觉

- **参考**：Claude Code 和 Gemini 的界面。学的是整体感觉（克制的配色、清楚的层级、留白），不照抄任何一家的品牌元素（标志、专属配色、字体）。
- **粒子效果**：参考 Gemini 的粒子效果，只用在欢迎页和 AI 思考中的占位处（见开头），不满屏都是。记忆库的展示页以后再定。
  - 用 CSS 或 Canvas 自己实现，不引入大的动画库；
  - 系统设置了「减少动态效果」时关掉；
  - 窗口不在前台、或者不在可见区域时停掉，不耗电。
- **统一一套样式**：颜色、字号、间距、圆角、按钮、标签页、列表，写成 CSS 变量，深浅两种配色都要。
- **做前端时调用 unslop 这个 skill**，按它的方向检查配色、间距、图标、文案和动效。
- 保持简洁，不加多余的说明文字和标签。

## 八、模块与接口（2026-11-19，待确认）

这一部分只改 `public/**`，不改后端接口；真要加后端接口时先列出来问。唯一的例外：侧栏要给单人聊天显示 AI 头像，`src/space.mjs` 的 `listItem()` 里成员多带一个 `engine` 字段。logo 在另外设计，这一部分沿用现在的 logo，定稿后再换。

| 模块 | 做什么 | 对外接口 |
| --- | --- | --- |
| `public/css/tokens.css`（新） | 颜色、字号、间距、圆角、阴影，深浅两套 | 只有 CSS 变量；其他样式只用变量，不写死颜色 |
| `public/js/slots.js`（新） | 挂载点：设置分类、资源库分类、空间设置标签、右侧栏面板都用它注册，以后加功能各加一个文件，不改布局 | `register(slot, { id, label, icon, order, when?(space), render(el, ctx), dispose?() })`；`list(slot, ctx)`。四个 slot：`settings`、`library`、`spaceTabs`、`panels` |
| `public/js/pages.js`（新） | 整页视图：左侧导航加右侧内容，用于全局设置和资源库 | `openPage('settings' \| 'library', sectionId?)`，路由 `#/settings/<id>`、`#/library/<id>`。某个页面一个分类都没注册时，侧栏不显示它的入口（资源库在角色卡做之前就不出现） |
| `public/js/rightbar.js`（新） | 右侧栏：能收起，顶部切换面板，一次看一个；当前空间用不上的面板不显示 | `showPanel(id)`；收起状态和上次看的面板记在本机 |
| `public/js/particles.js`（新） | Canvas 粒子 | `mountParticles(el, { mode: 'ambient' \| 'thinking' }) → { stop() }`。系统设置了「减少动态效果」就不画；窗口不在前台、元素不在可见区域时暂停 |
| 现有模块 | 侧栏里单人聊天显示 AI 头像；文件、改动面板改成右侧栏的两个面板；任务计划条挪进「计划」面板；设置窗口拆成「通用」「AI 连接」两个分类；空间设置改成标签（常规、成员、任务选项）；聊天区改无气泡 | 成员标签留一个空位：`setMemberMeter(memberId, { ratio, tip })`，上下文小圈以后由用量那部分来填 |

- 「定时任务」「上下文」等分类和面板由各自那部分注册，这一部分不建空壳。
- 验收：`npm run verify` 通过；`npm run mock` 下深浅两种配色各截一遍图；全程按 unslop 检查。
