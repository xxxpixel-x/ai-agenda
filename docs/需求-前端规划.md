# 需求：前端重新规划

- 整理：2026-11-18
- 起因：接下来要加角色卡、集市、定时任务、自定义 AI、额度和上下文，现在的设置窗口和右侧栏放不下。整体重新规划，右侧栏参考 Claude 桌面版。
- 不换框架：继续用现在的纯 JS 加 CSS，不引入 React 或打包工具。要的是统一的视觉风格，不是现成组件。
- **待定**：视觉参考（等截图）；聊天区、成员栏怎么重新规划还在想。

## 一、全局设置：整页，左侧导航

左下角「设置」打开后占满主区域，左边分类、右边内容，像系统设置那样。

| 分类 | 放什么 |
| --- | --- |
| 通用 | 语言、提醒、防睡眠、关窗口时缩到托盘 |
| AI 连接 | 每个 AI 一行：图标、名字、状态、额度。点开才显示程序位置、API key 等。自定义 ACP 接入也在这里（见 [需求-ACP接入](需求-ACP接入.md)） |
| 定时任务 | 所有空间的定时任务和运行记录（见 [需求-定时任务](需求-定时任务.md)） |

- 现在的设置窗口里每个 AI 都整块摊开；改成默认每个只显示一行，一眼看清哪些能用，要改的时候才展开。
- 分类以后再多也放得下，加功能不用改布局。

## 二、资源库：侧栏单独一个入口

- 位置在侧栏左下角「设置」旁边。
- 打开后同样是整页、左侧导航：角色卡、团队、skill 与 MCP、集市（见 [需求-角色卡](需求-角色卡.md)）。

## 三、空间设置：顶部标签

| 标签 | 放什么 |
| --- | --- |
| 常规 | 名字、共享文件夹、权限、已放行的程序、每次最多来回几次（聊天空间） |
| 成员 | 成员列表，从角色卡或团队添加；任务空间还有协调者 |
| 任务选项 | 只在任务空间：计划确认方式、审阅、自动通过、最多同时做几个 |
| 定时 | 这个空间的定时任务 |

## 四、新建空间

- 还是一个窗口。成员那一栏改成「从角色卡或团队添加」，也能像现在这样直接选 AI。
- 默认只露出最常用的几项，其他的收起来。

## 五、右侧栏：多面板

参考 Claude 桌面版的右侧栏：能收起，顶部切换几个面板，一次看一个。当前空间用不上的面板不显示。

| 面板 | 放什么 | 现在 |
| --- | --- | --- |
| 文件 | 共享文件夹、Markdown 预览、右键菜单 | 已有，右键菜单见 [需求-小功能](需求-小功能.md) |
| 改动 | 每次改动、对比、逐行批注 | 已有，批注见 [需求-小功能](需求-小功能.md) |
| 计划 | 任务空间的子任务、依赖、状态 | 现在是聊天上方的一条，挪进来，聊天区更清爽；聊天空间不显示 |
| 上下文 | 每个成员看到了什么 | 新加，见 [需求-上下文与额度](需求-上下文与额度.md) |

## 六、成员标签

- 加一个小圈，表示上下文用了多少，快满时变色。
- 鼠标停上去一次显示「上下文 X%、额度 Y%」。拿不到的数字就不显示。

## 七、视觉

- 等视觉参考定了，统一一套样式：颜色、字号、间距、圆角、按钮、标签页、列表，写成 CSS 变量，深浅两种配色都要。
- 保持简洁，不加多余的说明文字和标签。
