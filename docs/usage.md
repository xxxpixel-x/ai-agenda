# 使用指南

[返回项目首页](../README.md)

## 打开应用

双击项目文件夹中的 **`Agenda.exe`** 或桌面上的 **「Agenda」快捷方式**即可打开，不需要进入 cmd，也不会弹出命令行窗口。重复打开会回到已有窗口；关闭应用窗口即可退出。现有聊天记录和设置仍在原来的 `data/` 中。

删除空间：在左侧空间名称上右键，点「删除空间」，再确认删除；也可以在空间右上角「设置」中点「删除这个空间」。正在进行的讨论、任务和导入会先停止。软件创建的共享文件夹会一起删除；你自己选择的文件夹及里面的文件会保留。

请保留 exe 所在的完整项目文件夹；桌面使用快捷方式，不要只把 exe 移出去。开发者首次安装依赖后可用 `npm run build:launcher -- -DesktopShortcut` 生成启动器和桌面快捷方式。

## 支持的 AI

| AI | 怎么接入 | 需要做什么 |
| --- | --- | --- |
| **Claude Code** | 本机命令行（Claude 桌面 app 自带的那份） | 登录一次：在 PowerShell 运行软件里“连接与登录”显示的命令 |
| **Codex** | 本机命令行（Codex 桌面版自带） | 在 Codex 桌面版登录过即可 |
| **DeepSeek Harness** | 本机命令行（DeepSeek Harness 自带的 dsh） | 在 DeepSeek Harness 登录过即可 |
| **Gemini CLI** | 本机命令行（装了才出现） | 在终端运行一次 `gemini`，选用 Google 账号登录 |
| **Gemini** | Gemini API | 在“连接与登录”里填 API key（aistudio.google.com 创建） |
| **任意 OpenAI 兼容接口** | API | 在“连接与登录”里添加：DeepSeek、通义千问、Kimi、智谱、OpenAI、本地 Ollama 都有预设 |

命令行这几个用的是各自软件的账号和额度，不需要 API key。软件会自动找到它们装在哪；找不到时可以在“连接与登录”里手动填路径。

API key 保存在本机的 `data/settings.json`。桌面版在系统加密可用时使用 Electron safeStorage；系统加密不可用时会回退到明文，因此不要分享这个文件。

## 使用

- **新建空间**：选成员（同一种 AI 可以加多个，给不同名字和“额外设定”，比如“你负责挑毛病”）、选共享文件夹、选权限。
- **型号和思考档位**：每个成员可以选具体型号（列表里没有的可以直接填），以及这个型号支持的思考档位；选“默认”就用各 AI 自己的设置。

  | AI | 型号从哪来 | 思考档位 |
  | --- | --- | --- |
  | Claude Code | 软件里写好的常用型号（Opus / Fable / Sonnet / Haiku 各版本） | low / medium / high / xhigh / max |
  | Codex | Codex 自己的型号目录（`codex debug models`） | 按型号，最多 low 到 ultra |
  | DeepSeek Harness | 用 commandcode 服务商时读它的官方型号目录（套餐能用的都列出）；其他服务商只显示当前型号 | 按型号，例如 off / low / high / max |
  | Gemini CLI | 自动 / Pro / Flash / Flash-Lite（具体型号名可以手填） | 命令行没有这个参数，不能选 |
  | Gemini | Gemini API 的型号列表 | minimal / low / medium / high |
  | OpenAI 兼容接口 | 接口的 `/models` | minimal / low / medium / high / xhigh（各家支持的不同，不支持会报错） |

  DeepSeek Harness 选了档位时，第一次发言偶尔要多等十几秒（它的插件启动后要联网加载型号目录，加载完之前带档位的请求会被拒，软件会自动重发）。
- **共享文件夹**：
  - 新建一个空文件夹：由软件管理，里面先放一份 `共享文档.md`，适合写作、讨论、整理资料；
  - 或者用电脑上已有的文件夹：论文、方案、代码项目都行，AI 直接读写里面的文件。
- **权限**（随时可在“设置”里改）：
  - **只读**：只能看，不能改；
  - **可改文件**：可以改共享文件夹里的文件；
  - **可运行命令**：还可以在共享文件夹里跑命令、跑测试，**每条命令运行前先问你**。AI 的发言里会出现一张卡片，写着它想运行的命令：
    - **允许**：这一次放行；
    - **一直允许 npm**：这个程序以后在这个空间里都不再问（用 `&&`、`|` 连起来的命令，每一段的程序都放行过才不问）。放行过的程序在“设置”里能看到、能移除；
    - **拒绝**：可以补一句理由，AI 会按理由调整做法。
    - 卡片没人处理就一直等；窗口不在前台时，任务栏图标会闪，侧栏里这个空间会标出“等你确认”。点“停止”会取消这张卡片。
    - Claude Code 和 Codex 能先问；DeepSeek Harness 和 Gemini CLI 没法先问，在这一档只能读写文件，不能运行命令。任务协作里的 AI 不弹卡片，按权限直接执行。
  - **全部权限**：不受限制，可以读写电脑上任何地方、运行任何命令（Gemini CLI 能运行任何命令，但它的改文件工具仍只能碰共享文件夹；Gemini API 和 OpenAI 兼容接口仍只能改共享文件夹）。
  - 一个 AI 让另一个 AI 做事时：前三档里，删文件、大范围改你没提过的内容、有风险的命令，会先在聊天里问你；全部权限下直接照做。
  - 你账号上的外部连接（Codex 连的 Gmail、Slack、GitHub 等应用，以及插件、hooks、MCP 服务）：前三档里一律关掉，全部权限下照常可用。Claude Code 始终不加载你个人的插件、hooks 和 MCP。Gemini CLI 前三档不加载你的扩展和 MCP 服务。
  - AI 冒充不了你：每次发言时，软件都会给每条消息加一个随机标记，只有你自己发的消息才会被标成“我”。
- **发言规则**：
  - 你发一条消息后，成员依次发言，能看到前面所有人说的话、改的文件；
  - 消息里 `@某人`，就只有被点名的人回应；AI 之间互相 `@` 也会让对方接着说；
  - AI 觉得没有要补充的会跳过，大家都觉得说完了就停下来等你；另外有一个“每次最多来回几次”的上限；
  - 讨论中可以随时插话、停止、跳过当前发言；点顶上的成员标签，可以换它的型号和思考档位（下一次发言生效，讨论中也能换），或者让 TA 立刻发言；“继续讨论”让它们接着聊。
  - 任务协作在等你（确认计划、审查、回答问题）时，聊天输入框上方会出现一条提示，点“去处理”直接跳过去。
- **右侧文件面板**：
  - 查看、编辑、新建文件（Ctrl+S 保存）；
  - **改动记录**里每一条都能看对比、撤销。如果文件之后又被别人改过，撤销前会先提醒你。

## 导入别处的对话

在别的 AI 软件里聊到一半，想拉别的 AI 一起参与时：

- **已有空间**：点空间顶部的「导入对话」图标，选一段对话；
- **新建空间**：点「从对话开始」，共享文件夹会自动填上原对话的项目文件夹，对应的 AI 也会自动加进成员。

列表里自动列出本机这些软件的对话：Claude Code、Codex、DeepSeek Harness、Gemini CLI、WorkBuddy、ZCode。其他软件（网页版的 Gemini、ChatGPT、豆包、Kimi，以及 Trae 等）点列表上方的「粘贴或选文件」：

- **粘贴**：在聊天页面里全选复制，粘贴进来。带「You said / ChatGPT said」「我：/ 豆包：」这类说话人标记的会自动分出你和 AI；认不出时整段作为一条导入；
- **选文件**（或直接拖进来）：ChatGPT、Claude.ai 的导出文件（整个 `.zip` 就行，里面有很多段时再选一段）、Google Takeout 的 Gemini 活动记录、`.md` / `.txt` / `.json`。

各软件的记录位置和兼容情况见 [导入来源](importers.md)。

导入的对话在「聊天」和「任务协作」里都能看到，折叠成一块，点开能看全部。两处共用同一份记录，补导、简报采用或撤销会同步更新。它会作为固定背景交给聊天成员，以及任务的规划、审阅、执行和总结成员（不占“最近 40 条聊天记录”的名额），所以会按长度自动选择导入方式，导入时可以改：

| 长度 | 方式 |
| --- | --- |
| 1.5 万字以内 | 全部原文 |
| 1.5–6 万字 | 较早部分压成摘要，保留最近约 1.5 万字原文 |
| 6 万字以上 | 写一份交接文档存进共享文件夹，保留最近约 1 万字原文 |

另外还可以选“从某一条开始”导入，或者 **按主题** 导入。

**按主题**：只想把某一块交给别的 AI（比如在 Claude Code 里做游戏，剧本交给 Gemini），就选「按主题」，填“剧本”。整理的成员只挑出和剧本有关的内容，写成一份简报（背景 / 已经定下的 / 约束和接口 / 待讨论 / 相关原文），存成共享文件夹里的「主题-剧本.md」，其他成员只看到这份简报，看不到整段原对话。

- 原对话来自 Claude Code 时默认由接续的 Claude 来写；“对应成员”选「不加」，就由你选的成员来写，空间里也不会加 Claude。
- 成员或别的软件改了简报，要你在导入块上点「采用」才生效（可以先看对比，或者撤销）；你自己在文件面板里改的直接生效。
- 补导时只把新内容里和主题相关的部分并进简报。
- 新建空间时选了按主题，共享文件夹默认是原项目里的主题子文件夹（比如 `F:\game\剧本`），没有就自动建，这样其他成员默认在这个主题文件夹里工作；这不是对本机文件的完整安全隔离。

- **Claude Code 的对话**：对应的 Claude 成员会接着原会话继续，记得原来读过的文件、做过的操作。软件先把原会话复制一份再接着聊，app 里原来那段不会被改动。共享文件夹和原对话的文件夹不同时也能接续，但会先提醒你“原对话里的文件路径可能对不上”。
- **其他来源的对话**：只导入文字（双方说的话 + 每轮操作的简短记录）。Agenda 里有对应 AI 的（Codex、DeepSeek Harness、Gemini CLI），会让一个这种成员“认领”这段对话；没有的（WorkBuddy、粘贴的等）不加成员。粘贴和选文件导入的对话没有补导。
- **补导**：之后你又在原软件里接着聊了，打开空间时折叠块下面会出现「补导 N 条新内容」。补导后如果内容超过了当前方式的长度上限，会问你要不要重新压缩。
- 一个空间可以导入多段对话。导入完不会自动开始讨论，等你发话。

## 任务协作（参考 orca）

空间顶部切到 **「任务协作」**，写下一个目标，各个 AI 分工去完成。做法参考了 [orca](https://github.com/stablyai/orca) 的协调者 / 工作者模式：一次任务对应一张子任务依赖图，每次派活都有记录，工作者用三句话报告并写明成功或失败，需要人决定的事会停下来问你。

1. **规划**：你选的协调者把目标拆成子任务、定好负责人和依赖。勾选“先让其他成员审阅计划”时，其他成员会各提一次意见，协调者再定稿。
2. **你确认计划**：可以直接改每个子任务的标题、负责人、依赖、说明，也可以增删子任务，或者写下意见让协调者重新规划。
3. **执行**：依赖都已通过的子任务会派给负责人。
   - **git 项目**：每个子任务在独立的副本（git worktree）里进行，可以同时做（默认最多 3 个），互不干扰。你的项目本身在审查合并之前不会被改动。
   - **其他文件夹**：子任务按依赖顺序一个接一个做，直接改共享文件夹；每一步都记在改动记录里，可以撤销。
4. **审查**：子任务做完会停在“待你审查”。点开能看到它的报告、改了哪些文件（逐个看对比）、每一步操作，以及**终端视图（原始输出）**。
   - **通过**：git 项目会合并进这次任务的集成分支，依赖它的子任务这时才开始；
   - **带意见退回重做**：它会在原来的基础上改；
   - 如果和别的已通过的改动**冲突**，软件会让负责人在自己的副本里解决冲突，再交给你审查；
   - 它有问题要你决定时会停下来问你，你回答后它接着做；
   - 失败的可以重试、跳过或改派给别人。
5. **收尾**：全部完成后，协调者写一份总结，同时发到聊天里。git 项目点「合并到 main」（或你当前的分支）就会把所有通过的改动合并进你的项目，临时副本和分支自动清理。合并前，你的项目里不能有已跟踪文件的未提交改动。

如果勾选“做完自动通过”，子任务就不逐个审查了。任务进行时（规划、总结，以及“依次直接改”的执行阶段），聊天会暂停，避免两边同时改文件。

## 现在还没有的

- **任务协作里的命令审批**：任务协作中并行干活的 AI 不会弹审批卡片；DeepSeek Harness、Gemini CLI 在聊天里也弹不了。
- **独立安装包**：目前提供 `Agenda.exe` 启动器，仍需配套的项目文件和运行组件；首次源码安装可用 `启动.cmd`。

## 其他

| 命令 | 作用 |
| --- | --- |
| `npm start` | 打开桌面版 |
| `npm run mock` | 演示模式的桌面版：不调用任何 AI，用来看界面（数据存在 `data-mock/`） |

- 所有数据在 `data/` 文件夹里：`settings.json` 存设置，`spaces/` 存各空间的聊天记录、改动记录、软件建的共享文件夹，以及任务协作时各 AI 的临时副本（`spaces/<空间>/runs/`）。
- 任务协作的 git 分支都以 `agenda-` 开头；任务合并或取消后会自动删除。如果没合并就收起了任务，结果会留在 `agenda-<编号>` 分支上。
- 排查问题：设置环境变量 `RT_DEBUG_DIR=某个文件夹` 后启动，各 AI 输出的原始事件会写进那个文件夹。
- 桌面窗口里按 F12 打开开发者工具，Ctrl+R 刷新。
