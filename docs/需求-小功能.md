## 一、文件右键菜单

右侧文件面板里，右键点文件或文件夹弹出菜单（键盘：菜单键或 Shift+F10，和侧栏空间列表一样）。

| 菜单项 | 文件 | 文件夹 |
| --- | --- | --- |
| 在资源管理器中显示 | 打开所在文件夹并选中它 | 同左 |
| 用默认程序打开 | ✓ | — |
| 复制路径 | ✓ | ✓ |
| 复制相对路径（相对共享文件夹） | ✓ | ✓ |

- 「在资源管理器中显示」按系统换叫法：Windows「在资源管理器中显示」、macOS「在访达中显示」、Linux「在文件管理器中显示」；英文界面分别是 Show in Explorer / Reveal in Finder / Show in File Manager。
- 演示模式和网页版打不开系统窗口，只显示两个「复制」。
- 只能打开共享文件夹里面的路径，和现在顶部「在资源管理器中打开」按钮的限制一样。

## 二、在 diff 上逐行批注

- **只在 diff 上**：在改动记录里看某次改动的对比时，选中几行写一条批注。可以写好几条，攒好后点一次「发送」。
- **发给谁**：
  - **聊天空间**：发给改了这几行的成员（改动记录本来就记了是谁改的）。发出去是一条你的消息，自动 @ 这个成员，里面带文件路径、行号、引用的那几行和你的批注。批注涉及好几个成员时，每人一条消息，只带跟他有关的那几条。
  - **任务空间**：只在审查子任务时能批注，发送等于「打回」，批注附在打回理由里交给这个子任务的负责人。
- 没发送的批注切走再回来还在；关掉这个对比时提醒一句「有 N 条批注还没发」。

## 三、拖文件或图片进输入框

- 输入框支持拖进来和粘贴（截图直接 Ctrl+V / ⌘V）。发送前显示成输入框上方的小卡片，可以删掉。
- **图片**：直接发给能看图的成员；看不了图的成员，在它这次发言前提示一句「X 看不到图片」，然后照常发言。图片存在 Agenda 自己的数据目录里，聊天记录里能一直看到缩略图，不放进共享文件夹。
- **其他文件**：复制到共享文件夹的 `附件/` 下（重名自动加序号），消息里附上相对路径，成员自己去读。
  - Git 项目：把 `附件/` 写进本地的 `.git/info/exclude`，不出现在改动里，也不会被合并进项目。
  - 非 Git 项目的共享文件夹在任务执行期间只读时，不能加附件，提示原因。
- 单个文件的大小上限在实现时按各 AI 的限制定。

各 AI 能不能看图：

| AI | 怎么传图片 |
| --- | --- |
| Claude Code | stream-json 输入里带图片 |
| Codex | 命令行 `-i`，app-server 也有图片输入 |
| Gemini API / Gemini CLI | 支持，具体参数实现时确认 |
| OpenAI 兼容接口 | 看模型：先按支持发，接口报错就当作看不了图，以后这个接口不再发 |
| DeepSeek Harness | 实现时确认 |

## 四、合并时起草提交说明

- 任务空间点「合并进项目」时，协调者根据任务总结起草一份提交说明，填在确认框里，你可以改。现在固定是「Agenda 任务：目标第一行」（[taskrun.mjs](../src/taskrun.mjs) 的 `mergeIntoProject`）。
- 按项目最近的提交风格写：先读最近 20 条提交，照着它的语言、格式和长短写。
- 起草失败或协调者不可用时，退回现在的写法。
